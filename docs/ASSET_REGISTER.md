# LEVERAGE — Asset Register

**Every asset in this project is either (a) original procedural content
generated by this project's own Python forge scripts, or (b) the DejaVu
fonts (open license, recorded in `docs/LICENSES.md`).** Nothing was
downloaded from asset stores; no third-party models, textures, audio or
code are redistributed. Research into free-asset sources (Kenney,
Quaternius, Poly Pizza, OpenGameArt, Godot AssetLib) was performed during
environment investigation; the decision (see `docs/DECISION_LOG.md` D-04)
was to forge an original set so the art direction is distinctive and the
license story is trivially clean.

All generators are deterministic and live in `tools/forge/`:
`forge_lib.py` (noise/material helpers), `forge_world_tex.py`,
`forge_ui_tex.py`, `forge_audio_lib.py` (synthesis helpers),
`forge_audio.py`. Re-running them reproduces every file byte-for-byte
(seeded numpy RNGs).

## 8. 3D models & animations

**None external — by design.** All characters are procedurally skinned
meshes (`scripts/player/humanoid.gd`), all vehicles/city/interiors are
code-generated ArrayMesh/PrimitiveMesh geometry (`world_gen.gd`,
`vehicle.gd`, `interior_manager.gd`), and all animation is procedural
(`anim_driver.gd`). Zero glTF/FBX/blend files in the repo.
